Принципы

Правила, которые держат продукт цельным

1. Обзорник, не казино

Плотность контента и сравнение важнее игрового лобби. Сетки слотов — акцент, не каркас.

2. Деньги = зелёный

Единственный «громкий» цвет — CTA Play / Claim / Получить награду. Остальное тише.

3. Dual action

Всегда пара: ghost «Обзор» + solid «Играть». Выбор без ловушки одного клика.

4. Статус поверх шума

HOT / TOP / представитель читаются за секунду. Glow только у #1 и primary CTA.

5. Dark-first

Основная тема — тёмная. Light — производная токенов, не отдельный дизайн.

6. Trust over neon

Рейтинги, факты, отзывы. Неон и 3D — точечно в hero/promo, не в каждом ряду.

Цвет

Поверхности → текст → действие → статус

Палитра опирается на dark-каталоги 04/08/09 и зелёные CTA из 03/04/09. Фиолетовый — только для статуса/промо (TOP, rank glow), не как фон всего продукта.

Голос, правила, Do / Don’t

Микрокопирайт и визуальные запреты

Делать

  • «Играть» / «Обзор» / «Оставить отзыв» — одни и те же слова везде
  • Негативный отзыв без стигматизации
  • 18+ и ответственная игра на Card и Listing
  • Один зелёный CTA на зону внимания

Не делать

  • «Гарантированный выигрыш», агрессивный FOMO
  • Фиолетовый фон на весь экран
  • Сайдбар казино-лобби как главная модель
  • Glow на каждой карточке и pill-кластеры без смысла
